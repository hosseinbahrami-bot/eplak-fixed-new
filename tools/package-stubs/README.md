# `tools/package-stubs` — فایل‌های نشانه‌ی بسته‌ی آپلود

این پوشه **داخل بسته‌ی آپلود نمی‌رود**؛ فقط منبعِ فایل‌هایی است که
`tools/build-update-package.sh` هنگام ساختِ بسته در یک فضای موقت می‌سازد و با
مسیرِ درست داخل `eplak-fixed-update.zip` می‌گذارد:

| فایل | در بسته به چه مسیری می‌رود | چرا |
|---|---|---|
| `uploads-htaccess` | `uploads/.htaccess` | نگهبانِ اجرای اسکریپت در پوشه‌ی آپلود (محتوایش باید دقیقاً همان چیزی باشد که `shared/media.php → eplakMediaGuardContent()` می‌نویسد — آزمونِ `sms` این برابری را بررسی می‌کند) |
| `gitkeep` | `uploads/{reports,news,ads,tmp}/.gitkeep` و `data/.gitkeep` | تا خودِ پوشه‌ها بعد از Extract روی هاست وجود داشته باشند؛ بدون آن‌ها «آپلود عکس گزارش» و «دیتابیس SQLite» با «پوشه نوشتنی نیست» شکست می‌خورند |

چرا این‌جا و نه داخل خودِ `uploads/`؟ چون `uploads/` و `data/` داده‌ی زمانِ
اجرا هستند (در گیت نیستند) و آزمون‌های `backend`/`upload` در شروعِ کار
`uploads/` را پاک می‌کنند؛ پس فایلِ نشانه‌ی داخلِ آن‌ها پاک می‌شد و بسته
بی‌پوشه می‌ماند. این‌جا هیچ آزمونی پاکشان نمی‌کند.
