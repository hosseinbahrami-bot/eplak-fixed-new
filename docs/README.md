# راهنمای نصب، استفاده و ساختار پروژه EplakFixed

این مستند برای راهنمایی کاربر درباره ساختار پروژه، فایل‌های ایجادشده، نحوه نصب، راه‌اندازی و استفاده از پروژه اندروید و بک‌اند نوشته شده است.

## 1. معرفی پروژه

این پروژه یک نسخه اولیه و قابل‌گسترش از اپلیکیشن اندرویدی EplakFixed است که شامل موارد زیر می‌شود:
- ورود با شماره موبایل
- ثبت پروفایل کاربر
- ثبت گزارش/درخواست
- ثبت اطلاعات پرداخت
- ذخیره داده‌ها در دیتابیس محلی با Room
- پشتیبانی از اتصال به MySQL از طریق بک‌اند Node.js

## 2. ساختار پروژه

### پوشه اصلی پروژه
- `android-app/` : پروژه اندروید Kotlin
- `backend/` : سرور Node.js برای اتصال به MySQL
- `docs/` : مستندات پروژه

### ساختار اندروید

#### پوشه `android-app/app/src/main/java/com/example/eplakfixed/`
این پوشه شامل کدهای منطق اصلی برنامه است:

- `MainActivity.kt`
  - نقطه ورود برنامه
  - کاربر را به صفحه ورود هدایت می‌کند

- `LoginActivity.kt`
  - صفحه ورود کاربر
  - دریافت شماره موبایل و ذخیره اولیه کاربر

- `HomeActivity.kt`
  - صفحه اصلی برنامه
  - دربرگیرنده دکمه‌های ورود به بخش‌های مختلف

- `ReportActivity.kt`
  - صفحه ثبت گزارش/درخواست
  - دریافت عنوان، توضیحات و دسته‌بندی و ذخیره داده

- `ProfileActivity.kt`
  - صفحه پروفایل کاربر
  - دریافت نام، آدرس و کد ملی و ذخیره اطلاعات

- `PaymentActivity.kt`
  - صفحه ثبت اطلاعات قبض/پرداخت
  - دریافت شماره قبض، عنوان، مبلغ و تاریخ سررسید

- `AppDatabase.kt`
  - تنظیم دیتابیس Room
  - تعریف پایگاه داده و ایجاد آن

- `Entities.kt`
  - تعریف جداول و مدل‌های دیتابیس
  - شامل: `users`, `reports`, `payments`, `notifications`, `favorites`

- `Daos.kt`
  - کلاس‌های DAO برای انجام عملیات CRUD روی جداول

- `Repository.kt`
  - لایه داده برای مدیریت ذخیره‌سازی و دسترسی به دیتابیس

- `ApiService.kt`
  - رابط Retrofit برای ارسال داده‌ها به بک‌اند

- `CustomerRequest.kt`
  - مدل داده برای ارسال اطلاعات به سرور

#### پوشه `android-app/app/src/main/res/layout/`
این پوشه شامل فایل‌های XML صفحه‌های UI است:

- `activity_login.xml` : فرم ورود
- `activity_home.xml` : صفحه اصلی
- `activity_report.xml` : فرم ثبت گزارش
- `activity_profile.xml` : فرم پروفایل
- `activity_payment.xml` : فرم ثبت پرداخت

#### پوشه `android-app/app/src/main/res/values/`
شامل فایل‌های تنظیمات UI و رشته‌ها است:
- `strings.xml` : متن‌های برنامه
- `themes.xml` : تم و استایل برنامه
- `styles.xml` : استایل‌های سفارشی
- `colors.xml` : رنگ‌های برنامه

### ساختار بک‌اند

#### پوشه `backend/`
- `server.js` : سرور Node.js برای دریافت اطلاعات از اندروید و ذخیره در MySQL
- `mysql-schema.sql` : فایل ساخت جداول MySQL
- `package.json` : وابستگی‌های پروژه Node.js

## 3. نصب و راه‌اندازی

### 3.1 نصب پیش‌نیازها

برای اجرای این پروژه نیاز دارید:
- Java JDK 17 یا بالاتر
- Android Studio
- Node.js و npm
- MySQL Server

### 3.2 نصب و اجرای پروژه اندروید

1. Android Studio را باز کنید.
2. پوشه `android-app` را به‌عنوان پروژه باز کنید.
3. Gradle Sync را انجام دهید.
4. یک شبیه‌ساز اندرویدی انتخاب کنید.
5. روی دکمه Run بزنید.

### 3.3 نصب و راه‌اندازی بک‌اند

1. به پوشه `backend` بروید:
   ```bash
   cd backend
   npm install
   ```
2. MySQL را روشن کنید.
3. فایل `mysql-schema.sql` را اجرا کنید تا دیتابیس و جداول ایجاد شوند.
4. تنظیمات اتصال در `server.js` را با اطلاعات MySQL خود ویرایش کنید.
5. سرور را اجرا کنید:
   ```bash
   npm start
   ```

### 3.4 تنظیم اتصال به MySQL

در فایل `backend/server.js` این بخش را با مقادیر واقعی خود جایگزین کنید:

```js
const pool = mysql.createPool({
  host: 'localhost',
  user: 'root',
  password: '',
  database: 'eplak_db'
});
```

## 4. نحوه استفاده از برنامه

### ورود
- کاربر شماره موبایل خود را وارد می‌کند.
- اطلاعات اولیه کاربر در دیتابیس ذخیره می‌شود.

### ثبت گزارش
- کاربر از صفحه خانه وارد بخش گزارش می‌شود.
- عنوان، توضیحات و دسته‌بندی را وارد می‌کند.
- داده در دیتابیس ذخیره می‌شود.

### ویرایش پروفایل
- کاربر می‌تواند نام، آدرس و کد ملی خود را ثبت کند.

### ثبت پرداخت
- کاربر شماره قبض، عنوان، مبلغ و تاریخ سررسید را وارد می‌کند.

## 5. توضیح فایل‌های مهم

### فایل‌های اندروید
- `MainActivity.kt` : ورودی اصلی برنامه
- `LoginActivity.kt` : ورود کاربر
- `HomeActivity.kt` : صفحه اصلی
- `ReportActivity.kt` : ثبت گزارش
- `ProfileActivity.kt` : ثبت/به‌روزرسانی پروفایل
- `PaymentActivity.kt` : ثبت اطلاعات پرداخت
- `AppDatabase.kt` : راه‌اندازی Room

- `Daos.kt` : دسترسی به داده
- `Repository.kt` : منطق ذخیره‌سازی

### فایل‌های بک‌اند
- `server.js` : دریافت و پردازش درخواست‌ها
- `mysql-schema.sql` : ساخت دیتابیس و جداول
- `package.json` : تعریف وابستگی‌ها

## 6. نکات مهم برای توسعه آینده

- برای اتصال کامل‌تر به سرور، می‌توان از Retrofit برای هر فرم استفاده کرد.
- برای مدیریت بهتر داده‌ها، می‌توان از ViewModel استفاده کرد.
- برای طراحی بهتر UI، می‌توان از Material Design 3 بهره برد.
- برای امنیت، استفاده از JWT و احراز هویت توصیه می‌شود.

## 7. نتیجه

این پروژه در حال حاضر یک نسخه اولیه و قابل اجرا از یک اپ اندرویدی با دیتابیس محلی و پشتیبانی MySQL است. با مطالعه این مستند، کاربر می‌تواند ساختار فایل‌ها، نصب و اجرای پروژه و نحوه استفاده از هر بخش را درک کند.
