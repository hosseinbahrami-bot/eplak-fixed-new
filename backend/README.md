# Eplak Backend

## Setup
1. Create MySQL database and run mysql-schema.sql.
2. Update credentials in server.js if your MySQL user/password differs.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```

## Endpoints
- POST /users
- POST /reports
- POST /payments
- POST /notifications
- POST /favorites
