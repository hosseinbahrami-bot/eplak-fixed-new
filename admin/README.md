# پنل ادمین ای‌پلاک

## امکانات فعلی
- داشبورد خلاصه
- مشاهده گزارش‌ها
- مدیریت کاربران
- مدیریت تیکت‌های شهروندان
- فیلتر بر اساس وضعیت و جست‌وجو
- پاسخ به تیکت‌ها
- حذف گزارش/کاربر/تیکت
